# Python Banking System

## 📌 Project Overview

The **Python Banking System** is a console-based application developed using **Object-Oriented Programming (OOP)** concepts in Python.

The system allows users to create bank accounts, deposit and withdraw money, check account balances, and view transaction history. The project demonstrates important OOP principles such as classes, objects, constructors, encapsulation, inheritance, polymorphism, and abstraction.

## 🎯 Objectives

- Understand and implement Object-Oriented Programming in Python.
- Create and manage bank accounts using classes and objects.
- Implement deposit and withdrawal operations.
- Maintain transaction history.
- Apply encapsulation, inheritance, polymorphism, and abstraction.
- Practice clean and structured Python programming.

## ✨ Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Validate transactions
- Handle invalid inputs and insufficient balance
- Demonstrate different OOP concepts

## 🧠 OOP Concepts Used

### 1. Classes and Objects

Classes are used to define the structure and behavior of bank accounts, while objects represent individual accounts.

### 2. Constructor

The `__init__()` constructor initializes account details such as account number, account holder name, and balance.

### 3. Encapsulation

Account data is controlled through class methods instead of allowing direct modification of important account information.

### 4. Inheritance

Specialized account classes can inherit common functionality from a base account class.

### 5. Polymorphism

Different account types can provide their own implementation of common methods while using the same method interface.

### 6. Abstraction

Common banking operations are defined through an abstract structure, hiding unnecessary implementation details from the user.
